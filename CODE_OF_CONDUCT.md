# Code of conduct

Deskmate is built for schools and community organizations, and we want this project to feel as welcoming as a good front office.

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, welcome newcomers and non-developers, and keep criticism about ideas, not people. Harassment of any kind is not tolerated.

Report concerns privately to the maintainers through a GitHub security advisory or the contact listed on the maintainers' profiles. Reports are handled confidentially.
