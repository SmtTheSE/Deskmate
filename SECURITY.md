# Security policy

Deskmate handles messages from students, parents, and staff, so we take security reports seriously.

Please **do not open a public issue** for vulnerabilities. Report them privately through GitHub's "Report a vulnerability" (Security Advisories) on this repository. We aim to acknowledge reports within 3 working days.

In scope: authentication and sessions, setup-code bypass, data exposure between requesters, webhook verification, PII leaking to model providers, stored secrets, and injection in any input.

See docs/ARCHITECTURE.md ("Security model") for the current design.
